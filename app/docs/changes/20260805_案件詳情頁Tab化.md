# 20260805_案件詳情頁Tab化

## 變更摘要
`app/bank/cases/[id]/page.tsx` 目前把 On-Chain Activity、AI Case Assessment 兩個卡片(之後再加 News Scan)垂直堆疊,頁面拉得很長。改成用 shadcn 既有的 `components/ui/tabs.tsx` 把這三塊收進同一個 Tab 區塊。

## 變更內容

### 1. Tab 結構(`app/bank/cases/[id]/page.tsx`)
在原本 On-Chain Activity / AI Case Assessment 卡片的位置,改成一個 Tabs 元件,分頁順序:
1. **On-Chain Activity** —— 內容就是現有的 `<CaseActivityTimeline c={c} />`,只在 `isRealContractMode` 且有 milestone 時才顯示這個 tab(mock 模式或還沒有任何鏈上紀錄時,這個 tab 直接不出現,不要顯示空分頁)
2. **AI Case Assessment** —— 內容是現有的 AI 評估區塊,永遠顯示
3. **News Scan** —— 這次先放「即將推出」placeholder(說明文字 + 灰階圖示),等 [[20260805_負面新聞掃描功能]] 完成後直接把內容換掉,tab 結構不用再動

預設開啟的 tab:AI Case Assessment(現況最常被看的內容)。

### 2. 其他頁面不動
`app/exporter/status/[id]/page.tsx` 目前只有 `<CaseActivityTimeline c={c} />` 一塊,內容量還好,這次不改;之後如果也加 News Scan 給出口商看,再一併評估要不要 tab 化。

## 影響範圍
- `app/bank/cases/[id]/page.tsx`
- 使用既有元件 `components/ui/tabs.tsx`,不需要新增 UI 元件

## 對應 PRD 章節
- 純呈現方式調整,不影響資料模型或角色權限

## 決策依據
Kenneth 反應案件詳情頁太長。三個區塊(On-Chain Activity / AI Assessment / News Scan)性質上都是「同一案件的不同角度資訊」,適合用 tab 而非垂直堆疊。News Scan 功能還沒做完,但 Kenneth 選擇「三個一起做」—— 這裡先把 tab 骨架和 placeholder 做好,實際內容等 [[20260805_負面新聞掃描功能]] 確認並完成後再接上,避免之後還要重改一次版面結構。
