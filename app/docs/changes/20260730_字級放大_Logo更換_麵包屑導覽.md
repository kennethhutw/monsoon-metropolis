# 20260730_字級放大_Logo更換_麵包屑導覽

## 變更摘要
全站字級整體放大一階、Nav/登入頁/首頁的 logo 從 🔗 emoji 換成 `ms.png` 品牌圖示、所有子頁面(透過 PageLayout)加上自動生成的 breadcrumb 導覽列。

## 變更內容

### 1. 字級放大
- 現況:全站大量使用 `text-xs`(12px)當作主要內文/標籤字級,`text-[10px]`/`text-[11px]` 這種寫死的極小字也用了 57 處(bank/cases、dashboard、alerts 等頁最多)
- 做法:**不逐一改每個檔案的 className**,而是在 `src/app/globals.css` 的 `@theme` 區塊覆寫 Tailwind v4 的字級尺度變數(`--text-xs`、`--text-sm`...),讓全站套用 `text-xs`/`text-sm`/`text-lg` 等 class 的地方統一放大,一次生效、無需碰觸元件檔案:
  - `text-xs`  12px → 14px
  - `text-sm`  14px → 16px
  - `text-base` 16px → 18px
  - `text-lg`  18px → 20px
  - `text-xl`  20px → 22px
  - `text-2xl` 24px → 26px
  - `text-3xl` 30px → 32px
  - `text-4xl` 36px → 40px
  - `text-5xl` 48px → 52px
  - （行高是 Tailwind 內建的相對比例，字級變大會自動等比例放大，不用另外調)
- 另外把寫死的 `text-[10px]` / `text-[11px]`(57 處,19 個檔案)統一改成 `text-xs`,吃到上面的放大效果,同時清掉不必要的 magic number

### 2. Logo 換成 ms.png
- `ms.png`(1408×768,圓形風紋 icon,深藍色 #185fa5 系,跟現有主色一致)複製到 `public/ms-logo.png`
- 取代 3 處目前用 🔗 emoji 當 logo 的地方:`components/shared/Nav.tsx` 側邊欄、`app/(auth)/login/page.tsx` 登入頁、`app/page.tsx` 首頁轉導頁
- 圖片本身是寬版構圖、icon 置中,用 `object-cover` + 正方形容器裁切置中顯示，不會變形

### 3. Breadcrumb 導覽列
- 加在共用的 `components/shared/PageLayout.tsx`,所有走 PageLayout 的子頁面自動生效,不用每頁手動加
- 規則:「角色首頁(連結) › 所屬清單頁(連結,僅在更深層的詳情頁才出現) › 目前頁面標題(不可點,當前頁)」
  - 例:`/bank/dashboard` → **Bank**
  - 例:`/admin/users` → Admin › **User Management**
  - 例:`/bank/cases/TBC-2024-089` → Bank › Case Management › **Formosa Precision Electronics**
- 需要 `PageLayout.tsx` 加上 `'use client'`(要用 `usePathname()`)

## 影響範圍
- `src/app/globals.css`(新增/覆寫 `@theme` 字級變數)
- `components/shared/PageLayout.tsx`(加 breadcrumb 邏輯 + 'use client')
- `components/shared/Nav.tsx`、`app/(auth)/login/page.tsx`、`app/page.tsx`(logo 圖片)
- `public/ms-logo.png`(新增靜態檔案)
- 19 個頁面檔案的 `text-[10px]`/`text-[11px]` → `text-xs`(純字串取代,不動其他邏輯)

## 對應 PRD 章節
- 不對應特定 PRD 章節,屬於 UI 可用性調整
