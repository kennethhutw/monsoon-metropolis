# 20261006_AI評估輸出格式化

## 變更摘要
AI Case Assessment 目前是一整段純文字，不好閱讀。改成請模型輸出固定結構（建議 / 結論 / 重點 / 下一步），前端解析後以標籤、條列呈現。

## 變更內容
- **`app/api/ai/case/route.ts`**：在 `SYSTEM_PROMPT` 之後追加案件評估專用的輸出格式指示（只影響這條路由，不改全域 `SYSTEM_PROMPT`，其他 AI 路由不受影響）：
  ```
  RECOMMENDATION: APPROVE | REVIEW | REJECT
  SUMMARY: 一句話結論
  KEY POINTS:
  - 3 到 4 點，每點精簡、帶具體數字
  ACTION: 給審核人員的一句話下一步
  ```
- **`components/shared/AiAssessmentPanel.tsx`**：新增解析與呈現
  - 解析成功：頂部顯示建議標籤（APPROVE 綠 / REVIEW 黃 / REJECT 紅）加結論句，下方為重點條列，最後是「Next step」一行
  - 解析失敗（模型沒照格式、或舊的純文字紀錄）：維持原本的純文字顯示，不報錯
  - 歷史紀錄裡的舊評估同樣以純文字顯示，資料庫內容不變、不需 migration

## 影響範圍
- `app/api/ai/case/route.ts`
- `components/shared/AiAssessmentPanel.tsx`
- 不影響資料表結構、其他 AI 路由、`lib/ai/types.ts` 的 `SYSTEM_PROMPT`

## 對應 PRD 章節
- 不對應 `Monsoon_App_PRD.md` 既有章節，屬於 AI 案件評估的呈現調整

## 決策依據
- 單一段落難以快速掃讀；銀行審核人員需要先看到「建議」再看理由
- 讓模型直接輸出結構，比事後用程式拆句可靠；解析失敗時退回純文字，確保不會因格式問題讓評估消失
- 已存的舊評估不回填、不改資料，風險最小
