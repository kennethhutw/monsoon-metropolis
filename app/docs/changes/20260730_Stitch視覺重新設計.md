# 20260730_Stitch視覺重新設計

## 變更摘要
依 `stitch_modern_fintech_redesign/` 資料夾裡的設計系統(DESIGN.md)與 5 張 Stitch 產出的實際畫面,把全站視覺重新設計,不改動任何資料邏輯/API/合約整合,純視覺層。

## 設計系統來源
- `stitch_modern_fintech_redesign/monsoon_financial_systems/DESIGN.md` — 完整 color/typography/spacing/shape/elevation tokens + 元件規則
- 5 張 mockup:`landing_page`、`sign_in`(採用版)、`login_sign_up`(不用)、`bank_financing_overview`、`bank_case_management`、`exporter_kyb_verification`

## 已確認的三個範圍決策
1. 登入頁採用 **sign_in** 版本(5 個角色 demo 按鈕,無 Create Account 分頁,符合現有無註冊流程的系統)
2. **新增行銷首頁**:取代現在 `/` 的自動轉導小頁面,建成有 Hero、Core Verification Infrastructure、Six-Step Approval Protocol、CTA 的完整行銷頁(文案改寫成 Monsoon 自己的故事與數字,不照搬 Stitch 範例裡的假數據如 "$1.24B TVL")
3. 沒有 mockup 對應的 21 個頁面,**依同一套設計 tokens 與元件規則類推**套用,不用逐頁另外出圖確認

## 技術轉換筆記
- Stitch 產出是純 HTML + Tailwind CDN + Google Fonts(Geist + JetBrains Mono)+ Material Symbols Outlined 圖示字型
- **字體**:Geist Sans 專案已用 `next/font/google` 載入；JetBrains Mono 需新增(同樣用 `next/font/google`，不用 CDN `<link>`，避免執行期外部依賴)
- **圖示**:Material Symbols Outlined 換成專案已安裝的 `lucide-react`(對應相近圖示),不新增圖示系統依賴
- **色彩/圓角/陰影**:把 DESIGN.md 的 tokens 併入 `src/app/globals.css` 的 `@theme` 區塊(沿用上次放大字級的做法：改一處、全站套用)，與現有 `--text-*` 字級 tokens 共存
- Dark mode：DESIGN.md 只定義 light mode，暫維持現有 light-only(不新增 dark 變體)

## 執行順序(規模很大，分階段進行，每階段完成會回報)
1. Design tokens 併入 `globals.css`(色彩、圓角、陰影、JetBrains Mono)
2. 共用元件重做:`Nav`、`PageLayout`(含 Breadcrumb 視覺)、按鈕/卡片/徽章等基礎樣式 — 這些改完，後面每頁改起來才會快
3. 新行銷首頁 `/`
4. 登入頁 `/login`(採 sign_in 版)
5. Bank Dashboard、Bank Case Management、Bank Case Detail — 有直接 mockup 對照
6. Exporter KYB — 有直接 mockup 對照
7. 其餘 21 頁類推套用（Bank 4 頁、Exporter 3 頁、Importer 2 頁、Researcher 1 頁、Admin 8 頁）
